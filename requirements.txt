# - google-genai: src/ingestion/embedder.py's GoogleProvider, the default
#   embedding provider (`from google import genai`, `genai.Client(...)`) —
#   this package was missing from requirements.txt entirely, so the default
#   embedding path (gemini-embedding-001) could never actually run.
